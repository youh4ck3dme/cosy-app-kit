# Examples

Runnable Vitest examples for the Builder Kernel and Plugin SDK.

| Example | Command |
| --- | --- |
| [basic-command](./basic-command/) | `bun run test:unit examples/basic-command` |
| [custom-plugin](./custom-plugin/) | `bun run test:unit examples/custom-plugin` |
| [document-validation](./document-validation/) | `bun run test:unit examples/document-validation` |
| [undo-redo](./undo-redo/) | `bun run test:unit examples/undo-redo` |

These examples import library sources from `src/lib/*`. They are not separately published npm packages.
