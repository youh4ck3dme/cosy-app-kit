# Release: v0.4.7 — Plugin SDK Foundation

## Tags

| Tag | Notes |
| --- | --- |
| `v0.4.7-plugin-sdk` | Points at merge of Plugin SDK PR on cosy `main` |

## Added

- Isolated `src/lib/plugin-sdk/`: manifests, permissions, lifecycle FSM, `PluginSdkRegistry`
- Zod manifest validation
- Sealed `PluginContext` with permission-gated read accessors
- Unit suite `src/lib/plugin-sdk/plugin-sdk.test.ts`

## Changed

- None to Builder Kernel public API in this release (separate package)

## Security

- Manifest permissions deep-frozen after validation
- Context grant lists frozen; `permissions.push` escalation rejected (strict mode)
- `remove()` lifecycle hardening (see commit history on the feature branch)

## Breaking changes

- None

## Migrations

- None
- **Not wired** to `src/lib/builder/plugins/PluginRegistry`
- Write/modify permissions exist in the enum but do not expose write APIs on context
