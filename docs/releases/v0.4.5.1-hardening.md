# Release: v0.4.5.1 — Builder Kernel hardening

## Tags

| Tag | Notes |
| --- | --- |

## Added

- Reality-check / hardening regression tests under `src/lib/builder/`

## Hardened / Changed

- Sealed document access (`getDocument` clone / readonly freeze path)
- Document invariants after mutations
- Undo/redo exception safety
- Batch / transaction semantics
- Plugin permission defaults denying native overwrite without explicit grant

## Security

- Fail-closed integrity after command execute
- External callers cannot alias kernel document memory via getters

## Breaking changes

- None intended for product app (kernel still library-only)
- Callers that relied on mutating `getDocument()` results in place would observe isolation (clone semantics)

## Migrations

- None for product routes (kernel not wired)
