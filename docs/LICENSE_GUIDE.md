# License guide

## Current status

- Root [`LICENSE`](../LICENSE) states **proprietary / all rights reserved**.
- The npm package is `"private": true`.
- No OSI-approved open-source license has been adopted.

## Implications

- Do not assume MIT/Apache permissions for redistribution.
- Portfolio presentation may show architecture and documentation; legal reuse requires an explicit future license grant.

## Planned

Adopting an OSI-approved license (for example MIT or Apache-2.0) remains a **copyright-holder decision**. Documentation authors must not invent that grant.

## Third-party components

Runtime dependencies are declared in `package.json` / `bun.lock` and carry their own licenses. Automated license scanning in CI: **Not yet implemented**.
